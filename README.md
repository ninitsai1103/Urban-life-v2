## 功能說明

### 會員登入

以簡潔的表單畫面呈現，新使用者可以選擇以下兩種註冊方式：

- **一般註冊**：提供基本的註冊表單，填寫個人信息後即可註冊。
- **第三方註冊/登入**：支援使用Google帳號進行註冊和登入，簡化註冊流程。

已經註冊過的會員可以使用註冊的電子信箱及密碼進行登入。

### 忘記密碼

使用者可使用「忘記密碼」功能進行密碼重設。系統會先判斷資料庫中是否存在該電子信箱，若存在，則會發送驗證碼到該信箱。使用者輸入驗證碼及新密碼，即可完成密碼變更。

### Google登入

使用Firebase串接Google API，成功登入後會將Google帳戶的`displayName`、`email`、`uid`、`photoURL`寫入資料庫，用戶無需設定密碼即可完成登入。

### 會員註冊

如果使用者選擇一般註冊，將進入註冊頁面。此處使用者需要填寫完整的個人資料，並進行前端表單驗證。系統會檢查資料格式是否正確，如電子信箱已被註冊或其他格式錯誤，系統會跳出錯誤通知。通過所有驗證後即可完成註冊。

### 個人資料頁

在個人資料頁面，使用者可首次註冊時填寫帳戶資訊。部分資料如帳戶資訊在註冊後不可變更，但會員照片和密碼可以多次修改。完整的個人資料有助於會員在下單時快速填寫收件人資訊。

### 收藏

會員可以在會員中心查看已收藏的商品、課程、文章等內容，方便日後瀏覽。
